# Working Machines Plugin

Official Cursor plugin for [Working Machines](https://www.workingmachines.dev).

Connect Cursor to **1,400+ apps** and **15,000+ machine-ready actions** through a secure, remote Model Context Protocol (MCP) server.

## Overview

This plugin enables Cursor agents to discover, authenticate, and execute automations across 1,400+ third-party tools via Working Machines.

## Configuration

- **MCP Server**: Configured via `mcp.json` pointing to `https://app.workingmachines.dev/mcp`.
- **Skill**: Documented in `skills/working-machines/SKILL.md`.
